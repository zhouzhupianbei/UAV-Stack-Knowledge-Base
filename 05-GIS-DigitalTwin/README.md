## 🌍 技术流程

```mermaid
graph LR
    subgraph 数据采集
        A1[无人机航拍] --> A2[POS 数据]
        A2 --> A3[像控点测量]
    end
    
    subgraph 内业处理
        B1[空三加密] --> B2[密集匹配]
        B2 --> B3[网格构建]
        B3 --> B4[纹理映射]
    end
    
    subgraph 成果输出
        C1[OSGB] --> C2[3D Tiles]
        C2 --> C3[glTF/GLB]
        C3 --> C4[点云 LAS]
    end
    
    subgraph Web 展示
        D1[CesiumJS] --> D2[图层管理]
        D2 --> D3[量测标注]
        D3 --> D4[飞行模拟]
    end
    
    数据采集 --> 内业处理
    内业处理 --> 成果输出
    成果输出 --> Web 展示
```
