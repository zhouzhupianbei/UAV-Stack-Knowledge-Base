## 一、地面站概述

### 1.1 核心功能

**飞行监控：**
- 实时姿态显示
- 位置跟踪
- 电池状态
- 信号强度

**任务规划：**
- 航点设置
- 航线编辑
- 任务上传
- 任务执行

**参数配置：**
- 飞控参数
- 传感器校准
- 遥控器设置
- PID 调参

**日志分析：**
- 飞行日志下载
- 数据分析
- 故障诊断

### 1.2 主流地面站

| 地面站 | 平台 | 适用飞控 | 特点 |
|--------|------|---------|------|
| **QGroundControl** | 全平台 | PX4/ArduPilot | 跨平台、界面现代 |
| **Mission Planner** | Windows | ArduPilot | 功能最全、插件丰富 |
| **APM Planner** | 全平台 | ArduPilot | 轻量级 |
| **UGCS** | 全平台 | 多飞控 | 专业航线规划 |

## 二、QGroundControl 详解

### 2.1 安装部署

**Windows 安装：**
```powershell
# 下载安装包
https://github.com/mavlink/qgroundcontrol/releases

# 运行安装程序
QGroundControl.Installer.exe
```

**Linux 安装：**
```bash
# 添加仓库
sudo usermod -a -G dialout $USER
sudo apt-get install -y gstreamer1.0-plugins-bad \
    gstreamer1.0-libav gstreamer1.0-gl

# 下载 AppImage
wget https://github.com/mavlink/qgroundcontrol/releases/latest/download/QGroundControl.AppImage
chmod +x QGroundControl.AppImage
./QGroundControl.AppImage
```

**macOS 安装：**
```bash
# 下载 DMG
https://github.com/mavlink/qgroundcontrol/releases

# 拖拽到应用程序文件夹
```

**Android/iOS：**
- 应用商店搜索"QGroundControl"
- 或从官网下载 APK

### 2.2 界面布局

```
┌─────────────────────────────────────────┐
│  菜单栏  │ 工具栏 │ 状态栏              │
├─────────────────────────────────────────┤
│                                         │
│           3D 地图视图                    │
│                                         │
├─────────────────────────────────────────┤
│  飞行 │ 任务 │ 参数 │ 分析 │ 设置      │
└─────────────────────────────────────────┘
```

### 2.3 基本操作

**连接飞控：**
1. USB 连接或数传连接
2. 自动识别端口
3. 点击连接

**传感器校准：**
```
车辆设置 → 传感器 → 加速度计校准
→ 按提示放置飞机 → 完成
```

**航线规划：**
```
任务编辑 → 添加航点 → 设置高度/速度
→ 上传任务 → 执行
```

### 2.4 高级功能

**自定义仪表：**
```xml
<!-- Instrumentation.xml -->
<Instrumentation>
  <Bar name="Altitude" value="[altitude]"/>
  <Bar name="Speed" value="[airspeed]"/>
  <Bar name="Battery" value="[battery_voltage]"/>
</Instrumentation>
```

**虚拟遥控器：**
- 内置软件遥控器
- 支持游戏手柄
- 支持物理遥控器

## 三、Mission Planner 详解

### 3.1 安装部署

**Windows 安装：**
```powershell
# 下载安装包
https://firmware.ardupilot.org/Tools/MissionPlanner/

# 运行安装
MissionPlanner-latest.msi
```

**Linux（通过 Wine）：**
```bash
sudo apt install wine
wine MissionPlanner-latest.msi
```

### 3.2 界面布局

```
┌─────────────────────────────────────────┐
│  菜单栏 │ 快捷工具栏                     │
├──────────────┬──────────────────────────┤
│              │                          │
│   飞行数据   │      HUD 显示            │
│              │                          │
├──────────────┼──────────────────────────┤
│  功能按钮区  │      地图视图            │
└──────────────┴──────────────────────────┘
```

### 3.3 核心功能

**初始设置向导：**
```
初始设置 → 可选硬件 → 按步骤配置
- 机架类型选择
- 飞控固件上传
- 加速度计校准
- 罗盘校准
- 遥控器校准
- 电调校准
```

**调参优化：**
```
调参 PID → 选择模式 → 调整参数
→ 保存参数 → 试飞验证
```

**日志分析：**
```
数据日志 → 下载日志 → 选择日志
→ 查看图表 → 分析问题
```

### 3.4 插件系统

**常用插件：**
- MAVProxy（命令行地面站）
- Simulink（模型仿真）
- MATLAB（数据分析）
- 自定义插件开发

**插件开发：**
```csharp
// IPlugin 接口
public interface IPlugin
{
    void Init(MainV2 mainForm);
    void Loop();
    bool Unload();
}

// 实现插件
public class MyPlugin : IPlugin
{
    public void Init(MainV2 mainForm) {
        // 初始化
    }
    
    public void Loop() {
        // 循环执行
    }
    
    public bool Unload() {
        // 卸载
        return true;
    }
}
```

## 五、选型建议

### 5.1 使用场景

**选择 QGroundControl：**
- ✅ 需要跨平台（Mac/Linux）
- ✅ 需要移动端支持
- ✅ 喜欢现代界面
- ✅ PX4 用户

**选择 Mission Planner：**
- ✅ Windows 用户
- ✅ 需要深度调参
- ✅ 需要插件扩展
- ✅ ArduPilot 用户

### 5.2 组合使用

**推荐方案：**
- 外业飞行：QGroundControl（平板/手机）
- 内业调参：Mission Planner（PC）
- 日志分析：两者结合

## 六、实战技巧

### 6.1 QGC 技巧

**快捷键：**
- `Ctrl+M`：切换地图模式
- `Ctrl+V`：切换视图
- `Esc`：返回上一级

**自定义设置：**
```
设置 → 常规 → 单位设置
设置 → 遥测 → 端口配置
设置 → 视频 → 流媒体配置
```

### 6.2 MP 技巧

**快捷键：**
- `F1`：飞行数据
- `F2`：飞行计划
- `F3`：参数配置
- `F4`：调参 PID

**快速命令：**
```
# 控制台输入
arm         # 解锁
disarm      # 上锁
takeoff 10  # 起飞到 10 米
land        # 降落
rtl         # 返航
```

### 6.3 故障排查

**连接失败：**
- 检查端口是否正确
- 检查波特率（通常 57600）
- 检查驱动是否安装
- 重启地面站

**视频不显示：**
- 检查图传频率
- 检查视频格式
- 检查 GStreamer 安装
- 重启数传

## 七、扩展开发

### 7.1 QGC 二次开发

**环境搭建：**
```bash
git clone https://github.com/mavlink/qgroundcontrol.git
cd qgroundcontrol

# 安装 Qt
# 编译
qmake qgroundcontrol.pro
make
```

### 7.2 MP 插件开发

**开发环境：**
- Visual Studio 2019
- .NET Framework 4.7.2
- Mission Planner 源码

**示例插件：**
```csharp
using MissionPlanner.Plugins;

public class HelloWorld : IPlugin
{
    public void Init(MainV2 mainForm) {
        MessageBox.Show("Hello World!");
    }
    
    public bool Unload() {
        return true;
    }

```
