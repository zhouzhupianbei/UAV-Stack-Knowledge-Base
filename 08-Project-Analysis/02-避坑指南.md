# 避坑指南

> 项目实战中的常见问题与解决方案 —— 少走弯路

---

## 一、需求阶段

### 坑 1：需求不明确

**问题：**
- 客户说"要巡检"，但没说清楚巡什么
- 验收标准模糊
- 范围边界不清

**后果：**
- 反复修改
- 成本超支
- 验收困难

**正确做法：**
```markdown
# 需求确认清单

## 1. 巡检对象
- [ ] 具体设备类型（杆塔/导线/绝缘子）
- [ ] 数量（多少基杆塔、多少公里线路）
- [ ] 电压等级（110kV/220kV/500kV）

## 2. 检测内容
- [ ] 可见光检测（锈蚀/破损/异物）
- [ ] 红外检测（温度异常）
- [ ] 激光雷达（通道距离）

## 3. 精度要求
- [ ] 缺陷识别准确率（>90%）
- [ ] 定位精度（<10cm）
- [ ] 图像分辨率（>2000 万像素）

## 4. 交付成果
- [ ] 巡检报告（PDF）
- [ ] 缺陷清单（Excel）
- [ ] 原始照片（JPG）
- [ ] 数据格式要求

## 5. 验收标准
- [ ] 功能验收（演示）
- [ ] 性能验收（实测）
- [ ] 文档验收（完整性）
```

## 二、方案阶段

### 坑 2：过度承诺 AI 能力

**问题：**
- 承诺 99% 识别准确率
- 忽略光照、天气、角度影响
- 不说明需要大量训练数据

**后果：**
- 实际效果达不到承诺
- 客户不满意
- 尾款难收

**正确做法：**
```markdown
# AI 能力说明模板

## 1. 识别能力
- 常见缺陷识别率：>90%
- 罕见缺陷识别率：>70%
- 误报率：<10%

## 2. 限制条件
- 光照要求：白天、光线充足
- 天气要求：无雨、风速<5 级
- 拍摄角度：45°-90°
- 拍摄距离：5-30 米

## 3. 数据要求
- 训练数据：>5000 张标注图片
- 持续优化：每月更新模型
- 现场调优：1-2 周

## 4. 人工复核
- AI 识别结果需人工复核
- 复核比例：100%
- 复核时间：每基杆塔 1-2 分钟
```

## 三、实施阶段

### 坑 3：低估现场复杂度

**问题：**
- 只算飞行时间，不算转场时间
- 忽略天气影响
- 不考虑电磁干扰

**后果：**
- 工期延误
- 成本超支
- 人员疲惫

**正确做法：**
```markdown
# 工期估算模板

## 1. 飞行时间
- 每基杆塔：10 分钟
- 100 基杆塔：1000 分钟 = 17 小时

## 2. 转场时间
- 平均杆塔间距：500 米
- 转场时间：5 分钟/次
- 100 基转场：500 分钟 = 8 小时

## 3. 准备时间
- 每天出发准备：30 分钟
- 每天设备收纳：30 分钟
- 5 天准备：5 小时

## 4. 缓冲时间
- 天气影响：20%
- 设备故障：10%
- 总缓冲：30% = 9 小时

## 5. 总工期
- 理论时间：17 + 8 + 5 = 30 小时
- 加缓冲：30 × 1.3 = 39 小时
- 按每天 8 小时：39 / 8 = 5 天
```

## 四、交付阶段

### 坑 4：忽视数据交付标准

**问题：**
- 合同没写清楚交付格式
- 客户说成果不符合要求
- 正射影像精度不达标

**后果：**
- 返工
- 延期
- 扣款

**正确做法：**
```markdown
# 交付标准清单

## 1. 正射影像
- 格式：GeoTIFF
- 坐标系：CGCS2000
- GSD：5cm/像素
- 精度：平面<10cm，高程<15cm

## 2. 三维模型
- 格式：OSGB / 3D Tiles
- 纹理分辨率：4096×4096
- 坐标精度：<10cm

## 3. 缺陷报告
- 格式：PDF + Excel
- 缺陷照片：JPG，标注框选
- 位置信息：GPS 坐标

## 4. 原始数据
- 照片：JPG，含 EXIF
- 视频：MP4，H.264
- 日志：TXT

## 5. 验收流程
1. 甲方预审（3 个工作日）
2. 问题整改（2 个工作日）
3. 正式验收（1 个工作日）
4. 签字确认
```

## 五、运维阶段

### 坑 5：没有售后服务体系

**问题：**
- 客户找不到人
- 问题响应慢
- 没有备件支持

**后果：**
- 客户投诉
- 口碑差
- 复购率低

**正确做法：**
```markdown
# 售后服务方案

## 1. 服务渠道
- 电话：400-XXX-XXXX（工作日 9:00-18:00）
- 微信：技术支持群（7×24 小时）
- 邮件：support@company.com（24 小时内回复）

## 2. 响应时间
- 电话支持：即时响应
- 远程支持：2 小时内
- 现场支持：
  - 省内：24 小时
  - 省外：48 小时

## 3. 服务内容
- 技术咨询
- 故障排查
- 设备维修
- 软件升级
- 定期巡检（每年 1 次）

## 4. 备件支持
- 常用备件清单
- 备件价格表
- 备件库存：≥10% 设备量
- 停产产品：提前 6 个月通知，停产后供应 3 年

## 5. 培训计划
- 初级培训：设备操作（2 天）
- 中级培训：维护保养（2 天）
- 高级培训：故障排查（2 天）
- 复训：每年 1 次免费
```

## 六、商务阶段

### 坑 6：报价不合理

**问题：**
- 只算设备成本，忽略其他费用
- 低价中标，后期增项
- 没有预留利润空间

**后果：**
- 项目亏损
- 资金链断裂
- 公司倒闭

**正确做法：**
```markdown
# 成本估算表

## 1. 设备成本
| 项目 | 数量 | 单价 | 总价 |
|------|------|------|------|
| 无人机 | 2 套 | 15 万 | 30 万 |
| 负载 | 2 套 | 8 万 | 16 万 |
| 配件 | - | - | 5 万 |
| **小计** | - | - | **51 万** |

## 2. 人力成本
| 项目 | 人数 | 天数 | 单价 | 总价 |
|------|------|------|------|------|
| 飞手 | 2 | 10 | 2000 | 4 万 |
| 数据处理 | 2 | 5 | 1500 | 1.5 万 |
| 项目管理 | 1 | 15 | 3000 | 4.5 万 |
| **小计** | - | - | - | **10 万** |

## 3. 其他成本
| 项目 | 费用 | 说明 |
|------|------|------|
| 差旅 | 3 万 | 交通、住宿、餐饮 |
| 保险 | 0.5 万 | 设备险 + 第三方责任险 |
| 合规 | 1 万 | 空域申请、资质认证 |
| 税费 | 6.5 万 | 6% 增值税 |
| **小计** | **11 万** | - |

## 4. 总成本
- 设备：51 万
- 人力：10 万
- 其他：11 万
- **总成本：72 万**

## 5. 报价
- 成本：72 万
- 利润：30% = 21.6 万
- **报价：93.6 万**
```

## 七、风险管理

### 7.1 常见风险

| 风险 | 概率 | 影响 | 应对措施 |
|------|------|------|---------|
| 天气影响 | 高 | 中 | 预留缓冲时间、购买天气保险 |
| 设备故障 | 中 | 高 | 备用设备、快速维修 |
| 空域审批 | 中 | 高 | 提前申请、准备备选方案 |
| 人员安全 | 低 | 极高 | 安全培训、购买保险 |
| 数据丢失 | 低 | 高 | 多重备份、云端存储 |
| 客户违约 | 中 | 高 | 合同约束、分期付款 |

### 7.2 应急预案

```markdown
# 应急预案模板

## 1. 设备故障
- 现场：启用备用设备
- 无法修复：24 小时内调拨新设备
- 数据丢失：从备份恢复

## 2. 人员受伤
- 轻微伤：现场急救
- 重伤：立即送医
- 通知保险公司

## 3. 飞行事故
- 立即降落
- 保护现场
- 通知相关部门
- 配合调查

## 4. 数据泄露
- 立即断开网络
- 修改密码
- 通知客户
- 启动法律程序
```

## 八、案例分析

### 案例 1：电力巡检项目

**项目概况：**
- 客户：某省电力公司
- 内容：220kV 线路巡检，100 基杆塔
- 合同额：80 万
- 工期：10 天

**遇到的问题：**
1. 连续 3 天下雨，无法飞行
2. 2 套设备故障 1 套
3. 客户临时增加 20 基杆塔

**解决方案：**
1. 调整工期，增加 2 天缓冲
2. 启用备用设备，联系厂家维修
3. 签订补充协议，增加 16 万

**经验教训：**
- 工期预留 30% 缓冲
- 备用设备必须充足
- 变更必须签补充协议

### 案例 2：安防监控项目

**项目概况：**
- 客户：某市公安局
- 内容：无人机 + 机库，5 个点位
- 合同额：500 万
- 工期：90 天

**遇到的问题：**
1. 空域审批延迟 30 天
2. 网络环境复杂，图传不稳定
3. 培训人员水平参差不齐

**解决方案：**
1. 协助办理空域手续，专人跟进
2. 现场网络测试，增加 4G 备份
3. 分层次培训（基础班/进阶班）

**经验教训：**
- 空域审批提前 2 个月
- 复杂环境提前测试
- 培训分层次进行
