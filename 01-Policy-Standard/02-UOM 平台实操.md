# UOM 平台实操指南

> 民用无人驾驶航空器综合管理平台使用教程 —— 实名登记、飞行申请、空域查询

---

## 一、平台概述

### 1.1 平台定位

**UOM（Unmanned Aircraft Operation Management）** 是民航局官方无人机管理平台，于 2024 年 1 月 1 日随《无人驾驶航空器飞行管理暂行条例》同步上线。

**核心功能：**
- ✅ 实名登记
- ✅ 飞行申请
- ✅ 空域查询
- ✅ 驾驶员管理
- ✅ 违规查询

### 1.2 平台入口

| 入口 | 地址/名称 | 用途 |
|------|----------|------|
| 官网 | https://uom.caac.gov.cn | 电脑端操作 |
| App | "UOM"（应用商店） | 移动端操作 |
| 小程序 | "UOM 平台"（微信） | 快速查询 |

### 1.3 适用对象

| 用户类型 | 使用功能 |
|---------|---------|
| 个人用户 | 实名登记、飞行申请、空域查询 |
| 企业用户 | 单位登记、批量管理、运营资质 |
| 培训机构 | 学员管理、考试安排 |
| 管理部门 | 审批管理、数据监控 |

## 二、账号注册与认证

### 2.1 个人账号注册

**步骤 1：下载 App**
- 应用商店搜索"UOM"
- 或访问官网扫描二维码下载

**步骤 2：手机号注册**
```
打开 App → 点击"注册" → 输入手机号 → 获取验证码 → 设置密码
```

**步骤 3：实名认证**
```
登录 → 点击"我的" → 实名认证 → 上传身份证 → 人脸识别
```

**所需材料：**
- 本人手机号
- 二代身份证
- 本人面部（人脸识别）

**注意事项：**
- 手机号需与身份证一致
- 不支持港澳台及境外用户（需线下办理）
- 一个身份证只能注册一个账号

### 2.2 企业账号注册

**步骤 1：准备材料**
- 营业执照（统一社会信用代码）
- 法定代表人身份证
- 经办人身份证（如代办）
- 授权书

**步骤 2：在线注册**
```
官网 → 企业注册 → 填写企业信息 → 上传证照 → 等待审核
```

**审核时限：** 1-3 个工作日

## 三、无人机实名登记

### 3.1 登记要求

**需要登记的无人机：**
- 空机重量≥250g
- 或起飞全重≥250g
- 或带有摄像头等载荷

**无需登记的情况：**
- 玩具无人机（<250g、无摄像头）
- 室内飞行专用机

### 3.2 登记流程（App 端）

**步骤 1：进入登记页面**
```
登录 UOM App → 首页 → 无人机登记 → 新增登记
```

**步骤 2：填写无人机信息**

| 字段 | 说明 | 示例 |
|------|------|------|
| 无人机型号 | 选择或手动输入 | DJI Mavic 3 |
| 序列号（SN） | 机身或包装盒上 | 1581F01234567890 |
| 购买日期 | 发票或订单日期 | 2024-01-15 |
| 用途类型 | 个人/商业/政务等 | 个人娱乐 |
| 常用飞行区域 | 省市区 | 北京市朝阳区 |

**步骤 3：上传凭证（可选）**
- 购买发票
- 订单截图
- 无人机照片

**步骤 4：提交审核**
- 确认信息无误
- 提交登记申请

**步骤 5：获取登记码**
- 审核通过后生成二维码
- 下载并打印
- 粘贴于机身明显位置

### 3.3 登记流程（网页端）

```
登录官网 → 无人机管理 → 实名登记 → 填写信息 → 提交 → 打印登记码
```

**网页端优势：**
- 信息录入更方便
- 可直接打印登记码
- 适合批量登记

### 3.4 登记码使用

**打印要求：**
- A4 纸打印或贴纸打印
- 二维码清晰可扫描
- 防水防晒处理

**粘贴位置：**
- 机身底部或侧面
- 不易磨损位置
- 不影响飞行安全

**示例：**
```
┌─────────────────┐
│  无人机实名登记  │
│                 │
│   [二维码]      │
│                 │
│  登记号：UAV... │
│  所有人：张三   │
└─────────────────┘
```

### 3.5 登记信息变更

**需要变更的情况：**
- 所有权转移（买卖、赠与）
- 联系方式变更
- 无人机报废

**变更流程：**
```
登录 → 无人机管理 → 选择无人机 → 信息变更 → 提交
```

**所有权转移：**
- 原所有人：注销登记
- 新所有人：重新登记

## 四、飞行申请

### 4.1 需要申请的场景

| 情况 | 是否需要申请 | 说明 |
|------|------------|------|
| 微型无人机（适飞空域） | ❌ 不需要 | 真高 120 米以下 |
| 轻型无人机（视距内） | ❌ 不需要 | 适飞空域内 |
| 轻型无人机（超视距） | ✅ 需要 | 提前 1 天申请 |
| 小型及以上无人机 | ✅ 需要 | 无论空域 |
| 管制空域飞行 | ✅ 需要 | 提前 3-7 天 |
| 夜间飞行 | ✅ 需要 | 提前 1 天 |
| 人口密集区飞行 | ✅ 需要 | 提前 1 天 |

### 4.2 飞行申请流程（App 端）

**步骤 1：进入申请页面**
```
首页 → 飞行申请 → 新增申请
```

**步骤 2：填写飞行计划**

| 字段 | 说明 | 填写建议 |
|------|------|---------|
| 飞行时间 | 起止时间 | 预留缓冲时间 |
| 飞行区域 | 地图选点或坐标 | 明确边界 |
| 飞行高度 | 真高（米） | 一般<120 米 |
| 无人机 | 选择已登记的 | 确保登记有效 |
| 驾驶员 | 选择本人或他人 | 需有资质 |
| 飞行目的 | 航拍/巡检/测绘等 | 如实填写 |

**步骤 3：上传材料（如需）**
- 任务批文（政务任务）
- 空域协调证明
- 保险单

**步骤 4：提交申请**
- 确认信息无误
- 提交等待审批

**步骤 5：查看审批结果**
```
首页 → 我的申请 → 查看状态
```

### 4.3 飞行申请流程（网页端）

```
登录 → 飞行管理 → 飞行申请 → 填写计划 → 地图选区 → 提交
```

**网页端优势：**
- 地图选区更精确
- 可导入坐标文件
- 适合复杂任务

### 4.4 空域选择技巧

**适飞空域：**
- 绿色区域
- 无需申请
- 真高 120 米以下

**报告空域：**
- 黄色区域
- 需要提前报告
- 一般 1 天内审批

**管制空域：**
- 红色区域
- 原则上禁飞
- 特殊任务需军方/民航审批

### 4.5 审批时限

| 申请类型 | 提前时间 | 审批时限 |
|---------|---------|---------|
| 常规飞行 | 提前 1 天 | 24 小时内 |
| 管制空域 | 提前 3-7 天 | 3-7 个工作日 |
| 紧急任务 | 可加急 | 2-4 小时 |
| 大型活动 | 提前 15 天 | 7-15 个工作日 |

### 4.6 飞行报告

**飞行结束后需报告：**
```
登录 → 飞行管理 → 飞行报告 → 填写实际飞行情况 → 提交
```

**报告内容：**
- 实际飞行时间
- 实际飞行区域
- 是否发生异常
- 问题描述（如有）

## 五、空域查询

### 5.1 查询方法

**App 端查询：**
```
首页 → 空域查询 → 地图查看 → 点击区域查看详情
```

**网页端查询：**
```
首页 → 空域服务 → 空域地图 → 输入地点查询
```

### 5.2 空域标识

| 颜色 | 类型 | 飞行要求 |
|------|------|---------|
| 绿色 | 适飞空域 | 无需申请，<120 米 |
| 黄色 | 报告空域 | 提前报告 |
| 红色 | 管制空域 | 禁止飞行（特批除外） |
| 灰色 | 未知区域 | 谨慎飞行，提前咨询 |

### 5.3 常见禁飞区

**机场净空区：**
- 跑道中心 20km 内：禁止飞行
- 20-55km：需民航审批

**军事管理区：**
- 军事基地周边
- 边防海防线
- 军事设施

**政治敏感区：**
- 中南海、人民大会堂
- 外国驻华使领馆
- 核电站、水电站

**其他禁飞区：**
- 高铁站、火车站周边
- 大型活动现场
- 监狱、看守所

## 六、驾驶员管理

### 6.1 执照查询

```
登录 → 我的 → 驾驶员资质 → 查看执照信息
```

**执照信息：**
- 执照类型（VLOS/BVLOS/教员）
- 有效期
- 等级（轻型/小型/中型/大型）
- 发证机构

### 6.2 执照续期

**续期要求：**
- 提前 30 天申请
- 完成复训
- 通过理论考试

**续期流程：**
```
登录 → 驾驶员管理 → 执照续期 → 报名复训 → 参加考试 → 换发执照
```

### 6.3 违规记录查询

```
登录 → 我的 → 违规记录 → 查看历史
```

**违规类型：**
- 黑飞（未登记/未申请）
- 闯入禁飞区
- 超高度/超视距
- 伤人/损物

**影响：**
- 罚款
- 暂扣/吊销执照
- 纳入征信
- 刑事责任（严重情况）

## 七、常见问题

### Q1：登记后多久能拿到登记码？

**答：** 一般 1-3 个工作日审核通过，生成登记码。

### Q2：飞行申请被拒怎么办？

**答：** 
- 查看拒绝原因
- 修改飞行计划后重新申请
- 或咨询当地空管部门

### Q3：临时改变飞行计划怎么办？

**答：** 
- 小改动（时间微调）：无需重新申请
- 大改动（区域、高度）：需重新申请

### Q4：UOM 平台可以委托他人操作吗？

**答：** 
- 可以绑定多人管理同一架无人机
- 飞行时驾驶员需有资质

### Q5：境外无人机如何登记？

**答：** 
- 需提供购买凭证
- 通过 UOM 平台登记
- 部分品牌可能限飞

## 八、实操技巧

### 8.1 快速登记技巧

- 提前准备 SN 码照片
- 使用网页端批量登记
- 登记码塑封保存

### 8.2 飞行申请技巧

- 提前 1 天申请（避免临时被拒）
- 飞行区域略大于实际需求
- 预留缓冲时间（前后各 30 分钟）

### 8.3 应急处理

**飞行中遇到检查：**
1. 保持冷静，配合检查
2. 出示 UOM 登记码
3. 出示飞行申请（如需）
4. 出示驾驶员执照（如需）

**被误报扰航：**
1. 立即降落
2. 保留飞行记录
3. 配合调查
4. 提供 UOM 申请记录
