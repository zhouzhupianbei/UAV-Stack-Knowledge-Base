# 01-Policy-Standard：政策法规与行业标准

> 📋 合规是无人机应用的前提 —— 掌握法规、适航、禁飞区查询与行业标准

---

## 📌 模块定位

本模块面向**从业者与应用者**，提供无人机合规飞行的必备知识。在中国，合法合规飞行是开展任何无人机业务的前提条件。

---

## 🎯 目标读者

- 无人机行业从业者（必须掌握）
- 企业用户（采购/部署无人机系统）
- 个人飞手（合规飞行）
- 项目交付人员（验收标准参考）

## ⚠️ 重要提醒

**飞行前必须完成：**

1. ✅ 无人机实名登记（UOM 平台）
2. ✅ 操作员资质认证（视机型而定）
3. ✅ 飞行空域申请（如需）
4. ✅ 禁飞区查询确认
