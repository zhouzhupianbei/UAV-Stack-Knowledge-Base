# 禁飞区查询与飞行安全

> 禁飞区类型、查询方法、注意事项 —— 避免误入禁区

---

## 一、禁飞区类型

### 1.1 永久禁飞区

**机场净空区**
| 机场类型 | 禁飞范围 | 说明 |
|---------|---------|------|
| 运输机场 | 跑道中心 55km | 需民航局审批 |
| 通用机场 | 跑道中心 20km | 需空管部门审批 |
| 军用机场 | 周边 50-100km | 严禁飞行 |

**军事管理区**
- 军事基地、军营
- 军事训练场
- 武器试验场
- 边防、海防线
- 军事设施（雷达站、导弹阵地等）

**政治敏感区**
- 中南海、人民大会堂
- 钓鱼台国宾馆
- 外国驻华使领馆区
- 核电站、水电站
- 重要党政机关

### 1.2 临时禁飞区

**大型活动**
- 体育赛事（奥运会、亚运会等）
- 重要会议（两会、G20 等）
- 演唱会、展览会
- 节日庆典

**应急处置**
- 自然灾害现场（地震、洪水）
- 事故救援现场
- 公共卫生事件
- 社会安全事件

**临时管制**
- 重要人物出行
- 军事演习
- 航空表演
- 特殊任务

### 1.3 限制飞行区

**人口密集区**
- 城市建成区
- 商业区
- 居民区
- 学校、医院周边

**交通枢纽**
- 高铁站、火车站
- 汽车站
- 港口、码头
- 高速公路

**敏感设施**
- 监狱、看守所
- 广播电台、电视台
- 通信基站
- 石油、化工设施

## 二、禁飞区查询方法

### 2.1 UOM 平台查询（官方）

**App 端查询：**
```
打开 UOM App → 首页 → 空域查询 → 地图查看
```

**颜色标识：**
- 🟢 绿色：适飞空域（无需申请）
- 🟡 黄色：报告空域（提前报告）
- 🔴 红色：管制空域（禁止飞行）
- ⚪ 灰色：未知区域（谨慎飞行）

**网页端查询：**
```
登录 uom.caac.gov.cn → 空域服务 → 空域地图
```

### 2.2 厂商限飞区查询

**DJI Flysafe：**
- 官网：https://fly-safe.dji.com
- 功能：限飞区查询、解禁申请
- 数据：与官方同步更新

**查询步骤：**
```
访问官网 → 输入地点 → 查看限飞区 → 下载限飞区数据
```

### 2.3 第三方工具

| 工具 | 平台 | 特点 |
|------|------|------|
| 空域助手 | App | 实时查询、飞行记录 |
| 无人机管家 | App/网页 | 空域查询、飞行申请 |
| Flysafe | App | DJI 官方、限飞区查询 |

## 三、禁飞区解禁申请

### 3.1 可解禁的禁飞区

**DJI 限飞区：**
- A 类：机场净空区（不可解禁）
- B 类：敏感区域（可授权解禁）
- C 类：限高区域（可调整高度）

**官方管制空域：**
- 部分报告空域可申请
- 临时管制区到期自动解除
- 永久禁飞区不可解禁

### 3.2 解禁流程（DJI）

**步骤 1：准备材料**
- 身份证明
- 飞行任务证明
- 空域协调证明（如需）

**步骤 2：在线申请**
```
访问 fly-safe.dji.com → 解禁申请 → 填写信息 → 上传材料 → 提交
```

**步骤 3：等待审核**
- 审核时限：1-3 个工作日
- 审核结果：短信/邮件通知

**步骤 4：解锁飞行**
```
DJI Fly App → 限飞区提示 → 输入解禁密码 → 解锁
```

### 3.3 官方空域申请

**适用场景：**
- 政务任务
- 应急救援
- 商业拍摄（敏感区域）
- 科研测绘

**申请流程：**
```
UOM 平台 → 飞行申请 → 选择管制空域 → 上传批文 → 等待审批
```

**所需材料：**
- 任务批文（政府部门/军方）
- 空域协调证明
- 飞行计划
- 应急预案

## 四、误入禁飞区处理

### 4.1 预防误入

**飞行前准备：**
- [ ] UOM 平台查询空域
- [ ] DJI Flysafe 确认限飞区
- [ ] 观察周围环境
- [ ] 设置电子围栏（如有）

**飞行中注意：**
- [ ] 保持 GPS 信号
- [ ] 注意限飞区提示
- [ ] 不要强行突破限飞
- [ ] 随时准备返航

### 4.2 误入处理

**情况 1：起飞前发现**
- 立即取消飞行
- 移动到安全区域
- 重新规划飞行路线

**情况 2：飞行中发现**
```
1. 保持冷静，不要慌乱
2. 立即悬停
3. 观察周围环境
4. 原路返航或侧向飞出
5. 降落后检查设备
```

**情况 3：被强制降落**
```
1. 接受强制降落（保护设备）
2. 记录降落位置
3. 前往直升机点取回
4. 分析原因，避免再次发生
```

### 4.3 被查处应对

**遇到检查：**
1. 保持冷静，配合检查
2. 出示相关证件：
   - 身份证
   - 无人机登记码
   - 驾驶员执照（如需）
   - 飞行申请（如需）
3. 如实说明情况
4. 接受处理决定

**处罚类型：**
| 违规程度 | 处罚措施 |
|---------|---------|
| 轻微（首次） | 警告、教育 |
| 一般 | 罚款 1000-10000 元 |
| 严重 | 罚款 10000-100000 元、没收设备 |
| 特别严重 | 吊销执照、刑事责任 |

## 五、飞行安全规范

### 5.1 飞行前检查清单

**设备检查：**
- [ ] 电池电量充足（>90%）
- [ ] 螺旋桨完好无裂纹
- [ ] 云台保护已拆除
- [ ] 存储卡已插入
- [ ] 图传信号正常
- [ ] GPS 信号良好（>10 颗）

**环境检查：**
- [ ] 天气良好（无雨、风力<5 级）
- [ ] 不在禁飞区
- [ ] 周围无高压线
- [ ] 地面无人群聚集
- [ ] 有安全起降场地

**手续检查：**
- [ ] 无人机已登记
- [ ] 登记码已粘贴
- [ ] 飞行申请已获批（如需）
- [ ] 保险在有效期

### 5.2 飞行中安全规范

**高度限制：**
- 适飞空域：真高≤120 米
- 报告空域：按批准高度
- 管制空域：禁止飞行（特批除外）

**距离限制：**
- 视距内飞行：水平距离≤500 米
- 超视距飞行：需申请批准
- 远离人群：水平距离≥30 米

**速度限制：**
- 城市区域：≤50km/h
- 人口密集区：≤30km/h
- 空旷区域：按机型限制

**禁止行为：**
- ❌ 酒后飞行
- ❌ 夜间无照明飞行
- ❌ 穿越人群上空
- ❌ 追逐航空器
- ❌ 偷拍军事设施
- ❌ 运输违禁物品

### 5.3 应急处理

**失控返航：**
1. 保持遥控器开启
2. 等待自动返航
3. 观察返航路径
4. 准备手动接管

**低电量返航：**
1. 立即返航（不要贪飞）
2. 选择最短路径
3. 预留备降电量（15%）

**图传丢失：**
1. 等待自动返航
2. 观察无人机位置
3. 准备目视引导

**人员受伤：**
1. 立即降落
2. 救助伤员
3. 拨打 120
4. 保护现场
5. 联系保险公司

## 六、典型案例分析

### 案例 1：误入机场净空区

**案情：** 2024 年 6 月，李某在机场附近飞行，触发航班避让。

**处罚：**
- 罚款 50000 元
- 没收无人机
- 拘留 10 天

**教训：**
- 飞行前必须查询禁飞区
- 机场净空区绝对禁止飞行
- 可能危害航空安全，承担刑事责任

### 案例 2：大型活动违规飞行

**案情：** 2023 年 10 月，张某在演唱会现场飞行无人机。

**处罚：**
- 罚款 10000 元
- 没收无人机
- 纳入征信

**教训：**
- 大型活动现场临时禁飞
- 关注当地通告
- 不要抱有侥幸心理

### 案例 3：偷拍军事设施

**案情：** 2024 年 2 月，王某驾驶无人机拍摄军事基地。

**处罚：**
- 刑事拘留
- 没收设备
- 列入黑名单

**教训：**
- 军事设施绝对禁止拍摄
- 可能涉及危害国家安全
- 后果非常严重

## 八、常见问题

### Q1：如何确认所在区域是否禁飞？

**答：** 
1. UOM 平台查询（最权威）
2. DJI Flysafe 查询（参考）
3. 咨询当地空管部门
4. 观察周围是否有禁飞标识

### Q2：禁飞区边界模糊怎么办？

**答：** 
- 选择远离边界的安全区域
- 设置电子围栏
- 宁可保守，不要冒险

### Q3：农村偏远地区可以随便飞吗？

**答：** 
- 仍需遵守基本规定
- 避开军事设施、高压线
- 注意当地风俗习惯
- 建议仍做实名登记

### Q4：禁飞区数据多久更新一次？

**答：** 
- UOM 平台：实时更新
- DJI 限飞区：每周更新
- 临时禁飞区：随时可能发布

### Q5：被误判进入禁飞区怎么办？

**答：** 
- 保留飞行记录
- 向厂商申诉
- 如被处罚，可申请行政复议
