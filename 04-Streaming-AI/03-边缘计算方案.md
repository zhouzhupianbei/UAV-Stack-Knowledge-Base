## 一、边缘计算概述

### 1.1 为什么需要边缘计算

**云端处理的局限：**
- ❌ 延迟高（网络传输 + 云端处理）
- ❌ 带宽要求高（视频流上传）
- ❌ 依赖网络（无网无法工作）
- ❌ 隐私问题（数据上传）

**边缘计算优势：**
- ✅ 低延迟（本地处理，<100ms）
- ✅ 低带宽（只传结果）
- ✅ 离线工作
- ✅ 数据隐私

### 1.2 无人机边缘计算场景

| 场景 | 处理内容 | 延迟要求 |
|------|---------|---------|
| 目标检测 | YOLO 推理 | <100ms |
| 目标跟踪 | DeepSORT | <50ms |
| SLAM 定位 | ORB-SLAM | <30ms |
| 路径规划 | A*/RRT | <100ms |
| 避障 | 深度估计 | <50ms |

## 四、YOLO 边缘部署

### 4.1 TensorRT 部署

**导出 ONNX 模型：**
```python
from ultralytics import YOLO

model = YOLO('yolov8n.pt')
model.export(format='onnx', opset=13, simplify=True)
```

**转换为 TensorRT：**
```bash
# 使用 trtexec
/usr/src/tensorrt/bin/trtexec \
  --onnx=yolov8n.onnx \
  --saveEngine=yolov8n.engine \
  --fp16 \
  --workspace=4096
```

**TensorRT 推理：**
```python
import pycuda.driver as cuda
import pycuda.autoinit
import numpy as np
import cv2

class TRTInference:
    def __init__(self, engine_path):
        # 加载引擎
        with open(engine_path, 'rb') as f:
            runtime = trt.Runtime(trt.Logger(trt.Logger.WARNING))
            self.engine = runtime.deserialize_cuda_engine(f.read())
        self.context = self.engine.create_execution_context()
    
    def infer(self, image):
        # 预处理
        img = cv2.resize(image, (640, 640))
        img = img.transpose(2, 0, 1) / 255.0
        img = np.ascontiguousarray(img)
        
        # 推理
        inputs, outputs, bindings = self.allocate_buffers()
        cuda.memcpy_htod(inputs[0], img)
        self.context.execute(bindings=bindings)
        cuda.memcpy_dtoh(outputs[0], outputs[0])
        
        return outputs[0]

# 使用
trt = TRTInference('yolov8n.engine')
result = trt.infer(cv2.imread('test.jpg'))
```

## 六、实战案例

### 6.1 无人机巡检系统

**系统架构：**
```
机载 Jetson NX
├── 相机 → YOLO 检测
├── IMU → 姿态估计
├── GPS → 定位
└── 4G → 结果上传

地面站
├── 实时监控
├── 缺陷告警
└── 报告生成
```

**部署代码：**
```python
#!/usr/bin/env python3
import cv2
import rospy
from ultralytics import YOLO
from drone_msgs.msg import DefectDetection

class InspectionNode:
    def __init__(self):
        rospy.init_node('inspection_node')
        
        # 加载模型
        self.model = YOLO('power_line_defect.pt')
        
        # 发布缺陷检测结果
        self.pub = rospy.Publisher('/defect/detection', DefectDetection, 10)
        
        # 相机
        self.cap = cv2.VideoCapture(0)
        
        self.loop()
    
    def loop(self):
        rate = rospy.Rate(30)
        
        while not rospy.is_shutdown():
            ret, frame = self.cap.read()
            if ret:
                # 推理
                results = self.model(frame)
                
                # 发布结果
                msg = DefectDetection()
                msg.header.stamp = rospy.Time.now()
                
                for result in results:
                    for box in result.boxes:
                        cls = int(box.cls[0])
                        conf = float(box.conf[0])
                        
                        if conf > 0.8:
                            msg.defects.append(cls)
                            msg.confidences.append(conf)
                
                self.pub.publish(msg)
            
            rate.sleep()

if __name__ == '__main__':
    try:
        InspectionNode()
    except rospy.ROSInterruptException:
        pass
```

### 6.2 实时目标跟踪

```python
from sort import Sort
import numpy as np

class MultiObjectTracker:
    def __init__(self):
        self.tracker = Sort(max_age=20, min_hits=3, iou_threshold=0.3)
        self.track_history = {}
    
    def update(self, detections):
        """
        detections: [(x1, y1, x2, y2, score), ...]
        """
        tracks = self.tracker.update(np.array(detections))
        
        for track in tracks:
            track_id = int(track[4])
            x1, y1, x2, y2 = track[:4]
            
            if track_id not in self.track_history:
                self.track_history[track_id] = []
            
            self.track_history[track_id].append((x1, y1, x2, y2))
            
            # 保留最近 30 帧
            if len(self.track_history[track_id]) > 30:
                self.track_history[track_id].pop(0)
        
        return tracks
    
    def draw_tracks(self, frame, tracks):
        for track in tracks:
            track_id = int(track[4])
            x1, y1, x2, y2 = map(int, track[:4])
            
            # 绘制边界框
            cv2.rectangle(frame, (x1, y1), (x2, y2), (0, 255, 0), 2)
            
            # 绘制 ID
            cv2.putText(frame, f'ID:{track_id}', (x1, y1-10),
                       cv2.FONT_HERSHEY_SIMPLEX, 0.5, (0, 255, 0), 2)
        
        return frame
```

## 七、常见问题

### Q1：Jetson 内存不足怎么办？

**答：**
- 增加 swap 空间
- 使用更小的模型
- 降低输入分辨率
- 批处理改为单帧

### Q2：推理速度慢怎么办？

**答：**
- 使用 TensorRT 加速
- FP32 改为 FP16/INT8
- 降低模型复杂度
- 锁定 CPU/GPU 频率

### Q3：相机延迟高怎么办？

**答：**
- 使用 GStreamer 硬解码
- 降低分辨率/帧率
- 使用 CSI 接口（非 USB）
- 减少后处理
