# 动力系统详解

> 电机/电调/螺旋桨匹配计算 —— 打造高效可靠的动力系统

---

## 一、无刷电机原理

### 1.1 电机结构

**主要部件：**
- 定子（线圈）
- 转子（永磁体）
- 轴承
- 电机轴

**工作原理：**
```
电子换相 → 定子线圈产生旋转磁场 → 转子永磁体跟随旋转 → 输出扭矩
```

### 1.2 关键参数

| 参数 | 说明 | 单位 |
|------|------|------|
| KV 值 | 每伏特转速 | RPM/V |
| 最大电流 | 持续工作电流 | A |
| 最大功率 | 持续输出功率 | W |
| 极对数 | 磁极对数 | - |
| 内阻 | 线圈电阻 | mΩ |

**KV 值选择：**
| KV 范围 | 适用螺旋桨 | 特点 |
|--------|-----------|------|
| <500 | 15-30 寸 | 低转速、大扭矩 |
| 500-1000 | 8-15 寸 | 平衡型 |
| >1000 | 5-8 寸 | 高转速、低扭矩 |

### 1.3 电机计算

**转速计算：**
```
转速 (RPM) = KV 值 × 电池电压 (V)

例：920KV 电机，6S 电池 (22.2V)
转速 = 920 × 22.2 = 20,424 RPM (空载)
```

**功率计算：**
```
功率 (W) = 电压 (V) × 电流 (A)

例：22.2V × 20A = 444W
```

**推力估算：**
```
推力 (g) ≈ 功率 (W) × 效率系数

效率系数：
- 高效电机：8-10 g/W
- 普通电机：5-8 g/W
- 低效电机：3-5 g/W
```

## 二、电调（ESC）选型

### 2.1 电调作用

**核心功能：**
- 将直流电转换为三相交流电
- 控制电机转速
- 提供 BEC（电池消除电路）
- 保护功能（过流/过热/低压）

### 2.2 关键参数

| 参数 | 说明 | 选型建议 |
|------|------|---------|
| 持续电流 | 长期工作电流 | 电机最大电流 × 1.2 |
| 峰值电流 | 短时最大电流 | 电机峰值电流 × 1.2 |
| 支持电池 | 支持 S 数 | 匹配电池配置 |
| BEC 输出 | 5V/12V 输出 | 根据飞控需求 |
| 协议 | PWM/Oneshot/Dshot | 根据飞控支持 |

### 2.3 电调协议对比

| 协议 | 刷新率 | 延迟 | 推荐度 |
|------|-------|------|-------|
| PWM | 50-490Hz | 高 | ❌ 不推荐 |
| Oneshot125 | 8kHz | 中 | ⭐⭐ |
| Oneshot42 | 24kHz | 低 | ⭐⭐⭐ |
| Dshot600 | 600kHz | 极低 | ⭐⭐⭐⭐⭐ |
| Dshot1200 | 1.2MHz | 极低 | ⭐⭐⭐⭐⭐ |

## 三、螺旋桨选型

### 3.1 螺旋桨参数

**标识方法：**
```
例：1045 螺旋桨
- 前两位：直径 10 英寸
- 后两位：螺距 4.5 英寸
```

**常见规格：**
| 规格 | 直径 | 螺距 | 适用机型 |
|------|------|------|---------|
| 5040 | 5 寸 | 4 寸 | FPV 穿越机 |
| 9450 | 9.4 寸 | 5 寸 | 中型多旋翼 |
| 1555 | 15 寸 | 5.5 寸 | 大型多旋翼 |

### 3.2 螺旋桨匹配

**匹配原则：**
- 大桨 + 低 KV：高效率、长续航
- 小桨 + 高 KV：高机动、高速度

**匹配计算：**
```
桨尖速度 = π × 直径 × 转速

安全范围：桨尖速度 < 0.7 马赫 (约 238m/s)

例：10 寸桨，20000RPM
桨尖速度 = 3.14 × 0.254m × 333rps = 265m/s (接近极限)
```

### 3.3 材质对比

| 材质 | 优点 | 缺点 | 价格 |
|------|------|------|------|
| 塑料 | 便宜、耐用 | 效率一般 | 低 |
| 碳纤维 | 轻、刚性好 | 贵、易碎 | 高 |
| 木质 | 效率高、噪音低 | 易变形 | 中 |

## 四、电池系统

### 4.1 锂电池参数

| 参数 | 说明 | 典型值 |
|------|------|-------|
| 标称电压 | 单节 3.7V | 3S=11.1V, 6S=22.2V |
| 满电电压 | 单节 4.2V | 6S=25.2V |
| 放电电压 | 单节 3.0-3.5V | 6S=18-21V |
| 容量 | 电量存储 | 1000-22000mAh |
| 放电倍率 | 最大放电能力 | 20-100C |

### 4.2 电池选型

**容量选择：**
```
续航时间 (min) ≈ 容量 (Ah) × 放电系数 / 平均电流 (A)

例：10Ah 电池，平均电流 20A
续航 ≈ 10 × 0.8 / 20 = 0.4 小时 = 24 分钟
```

**放电倍率选择：**
```
最大放电电流 = 容量 × 放电倍率

例：5000mAh, 50C
最大电流 = 5Ah × 50 = 250A
```

### 4.3 电池保养

**充电注意：**
- 使用平衡充电器
- 充电电流≤1C（推荐 0.5C）
- 充满后及时取出

**存放注意：**
- 长期存放：50-60% 电量
- 存放温度：15-25℃
- 定期检查（每月）

**安全事项：**
- ❌ 不要过充过放
- ❌ 不要刺破电池
- ❌ 不要高温存放
- ✅ 使用防爆袋充电

## 五、动力系统匹配计算

### 5.1 推重比计算

**推重比要求：**
| 机型 | 最小推重比 | 推荐推重比 |
|------|-----------|-----------|
| 航拍机 | 2:1 | 3:1 |
| 穿越机 | 4:1 | 8:1 |
| 载重机 | 2:1 | 2.5:1 |

**计算示例：**
```
飞机重量：2kg
推荐推重比：3:1
总推力需求：2kg × 3 = 6kg = 6000g

四旋翼：单电机推力 = 6000/4 = 1500g
```

### 5.2 效率计算

**悬停效率：**
```
悬停效率 (g/W) = 单电机推力 (g) / 单电机功率 (W)

优秀：>10 g/W
良好：7-10 g/W
一般：5-7 g/W
```

**续航估算：**
```
续航 (min) = 电池能量 (Wh) × 放电系数 / 悬停功率 (W) × 60

例：6S 10Ah 电池，悬停功率 400W
续航 = 22.2V × 10Ah × 0.8 / 400W × 60 = 26.6 分钟
```

## 六、常见故障排查

### 6.1 电机故障

| 故障 | 可能原因 | 解决方法 |
|------|---------|---------|
| 电机抖动 | 轴承损坏、转子偏心 | 更换电机 |
| 电机发热 | 过载、散热不良 | 降低负载、改善散热 |
| 转速不稳 | 电调问题、信号干扰 | 检查电调、屏蔽线路 |
| 异响 | 轴承磨损、异物 | 清理、更换轴承 |

### 6.2 电调故障

| 故障 | 可能原因 | 解决方法 |
|------|---------|---------|
| 无法启动 | 供电问题、信号丢失 | 检查电源、信号线 |
| 突然停转 | 过热保护、过流保护 | 检查散热、降低负载 |
| 响应迟钝 | 协议不匹配、固件问题 | 更新固件、检查协议 |

### 6.3 振动问题

**振动来源：**
- 螺旋桨不平衡
- 电机轴承磨损
- 机架共振

**解决方法：**
- 做动平衡测试
- 更换高质量螺旋桨
- 增加减震措施
