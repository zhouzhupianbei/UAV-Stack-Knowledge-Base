## 🔧 核心技术栈

```mermaid
graph TB
    subgraph 飞行平台
        A1[多旋翼] --> A2[固定翼]
        A2 --> A3[垂起固定翼]
        A3 --> A4[直升机]
    end
    
    subgraph 动力系统
        B1[无刷电机] --> B2[电调 ESC]
        B2 --> B3[螺旋桨]
        B3 --> B4[电池系统]
    end
    
    subgraph 飞控系统
        C1[商业飞控] --> C2[开源飞控]
        C2 --> C3[自研飞控]
    end
    
    subgraph 传感器
        D1[IMU] --> D2[GPS/RTK]
        D2 --> D3[气压计]
        D3 --> D4[视觉/激光]
    end
    
    subgraph 图传系统
        E1[模拟图传] --> E2[数字图传]
        E2 --> E3[4G/5G 图传]
        E3 --> E4[卫星图传]
    end
    
    飞行平台 --> 动力系统
    动力系统 --> 飞控系统
    飞控系统 --> 传感器
    传感器 --> 图传系统
```
