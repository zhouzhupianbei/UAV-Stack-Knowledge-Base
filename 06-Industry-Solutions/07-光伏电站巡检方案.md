# 光伏电站巡检方案

> 从红外热斑到组件级故障定位 —— 无人机光伏电站巡检全流程
>
> 数据截止：2026-07 ｜ 适用：中国大陆大型地面电站、分布式工商业屋顶、山地与水面电站

---

## 一、方案概述

### 1.1 为什么必须用无人机

截至 2025 年底，中国累计光伏装机 **超 770 GW**（国家能源局口径），已建成全球最大光伏网络。地面电站普遍 100 MW—500 MW，组件数量 20 万—100 万块。传统人工巡检存在三个根本矛盾：

- **效率不可持续**：单 MW 人工巡检约 1.2—2 人天；500 MW 电站一次全检需 600 人天以上
- **漏检率天然存在**：人眼对 0.5℃ 温差热斑、组件内部隐裂、玻璃面微裂纹不敏感
- **安全风险高**：水面电站、屋顶电站、高海拔山地电站人工难以到达

**无人机 + 红外 + AI** 把单 MW 巡检成本从人工 1.2—2 人天降到 **0.05—0.1 人天**（含数据采集与初判），效率提升 **10—20 倍**，热斑识别准确率从人工 ~65% 提升到 **>90%**（陌讯多模态融合算法落地数据，CSDN 2025-08 实测误检率下降 79%）。

### 1.2 三大典型场景

| 场景 | 装机规模 | 巡检重点 | 推荐机型 |
|------|---------|---------|---------|
| 大型地面电站 | 100—1000 MW | 组件热斑 / PID / 隐裂 / 灰尘 / 遮挡 / 支架 | 垂起固定翼（续航 2h+）+ 多旋翼 |
| 工商业屋顶 | 1—50 MW | 组件热斑 / 屋面渗漏 / 配电箱 / 接线 | 中型多旋翼（M300/M350） |
| 山地 / 水面 | 50—500 MW | 组件 + 地形 / 水域环境 / 长距离图传 | 固定翼长航时 + 5G/卫星回传 |
| 分布式户用 | <1 MW | 重点组串定位 | 轻小型多旋翼（御 3 / Mavic 3） |

### 1.3 与传统方案对比

| 对比项 | 传统人工 | 无人机红外+AI |
|--------|---------|--------------|
| 单 MW 巡检耗时 | 1.2—2 人天 | 0.05—0.1 人天 |
| 热斑检出率 | ~65% | >90% |
| 单 MW 巡检成本 | 800—1500 元 | 80—200 元 |
| 高危场景可达性 | 低（屋顶 / 水面 / 山地） | 高 |
| 数据可追溯 | 纸质记录 | 数字化 + GIS 定位 |

## 二、典型缺陷类型与诊断逻辑

### 2.1 缺陷分类表

| 缺陷类型 | 物理特征 | 检测手段 | 红外特征 |
|---------|---------|---------|---------|
| **热斑** | 局部电池片短路 / 老化 / 焊带断裂 | 红外热像仪 | 局部温升 5—30 ℃ |
| **隐裂** | 电池片微裂纹 | EL 检测 / 可见光高分辨率 | 无明显温升 |
| **PID** | 电势诱导衰减 | 红外 + IV 曲线 | 整片温升偏高 |
| **灰尘遮挡** | 表面积灰 | 可见光 + 对比基线 | 局部温升 3—8 ℃ |
| **鸟粪 / 树叶** | 局部遮挡 | 可见光 + 红外 | 高温差热斑 |
| **玻璃破损** | 表面裂纹 | 可见光高分辨率 | 无明显热特征 |
| **接线盒故障** | 二极管失效 | 红外 + 可见光 | 单片高热 |
| **组串失配** | 多个组件异常 | 红外 + 性能分析 | 串内多片温度异常 |

### 2.2 热斑分级标准

参考 IEC 62446-3:2017 与 NB/T 32045-2018：

- **A 级（轻微）**：温差 ΔT < 5 ℃，建议下次常规巡检复查
- **B 级（中等）**：5 ℃ ≤ ΔT < 15 ℃，建议 30 天内维修
- **C 级（严重）**：ΔT ≥ 15 ℃ 或整片发暗，建议立即断电检修
- **D 级（紧急）**：接线盒 / 焊带可见烧痕，立即隔离

### 4.1 AI 缺陷识别算法

| 模型 | 适用缺陷 | 准确率 | 仓库 |
|------|---------|--------|------|
| **YOLOv8 / YOLOv9** | 热斑 / 玻璃破损 / 鸟粪 | mAP50 0.85—0.92 | [P-Darabi/SolarPanelsDefectDetector](https://github.com/P-Darabi/SolarPanelsDefectDetector) |
| **U-Net / SegNet** | 隐裂 / 焊带分割 | IoU 0.82—0.88 | [binyisu/PVEL-AD](https://github.com/binyisu/PVEL-AD) |
| **MNFI-Net** | 多尺度光伏缺陷 | 论文 SOTA | [lyc686/MNFI-Net](https://github.com/lyc686/MNFI-Net) |
| **PV-S3** | 半监督语义分割 | EAAI'25 | [abj247/PV-S3](https://github.com/abj247/PV-S3) |
| **红外 + 可见光融合** | 复杂背景热斑 | 误检 ↓79% | 陌讯多模态 |

### 4.2 GIS 定位与组串分析

- **厘米级 RTK 定位**：组件行列坐标精确到 ±2 cm
- **组串级故障定位**：通过温差分布反推故障组件所在的组串号
- **PR（性能比）评估**：结合辐照度数据，输出整站 PR 热力图

### 4.3 数据管理

| 数据类型 | 频率 | 存储量 |
|---------|------|--------|
| 红外 / 可见光原始 | 每次巡检 | 50—500 GB |
| 缺陷标注 | 每次巡检 | 10—100 MB |
| 组串性能曲线 | 每 15 min | 1—5 MB/天 |
| 维修记录 | 事件触发 | KB 级 |

推荐存储：对象存储（MinIO / OSS / S3）+ 时序数据库（InfluxDB / TDengine）+ GIS 数据库（PostGIS）。

## 五、典型案例

### 5.1 国家电投 500 MW 地面电站（西北）

- **设备**：大疆 M350 RTK + 禅思 H20T + 大疆机场 3
- **规模**：500 MW，组件 110 万块
- **周期**：月巡 1 次，单次 2 天
- **成果**：单次发现 C/D 级缺陷 237 处，整年挽回发电损失约 280 万元
- **来源**：行业客户案例与 CSDN 2026-03 山地光伏 AI 巡检全方案解析

### 5.2 华润电力 200 MW 水面电站（华东）

- **设备**：纵横 CW-15 垂起固定翼 + 红外载荷
- **挑战**：水面高反射干扰、阴雨高湿
- **方案**：多云候补 + 红外 + 可见光融合 + 后处理 PR 校准
- **成果**：热斑识别准确率从 78% 提升到 91%，水面反射误报下降 65%

### 5.3 华为 + 星逻智能 AI 巡检

- **平台**：星逻智能机巢 + 华为昇腾 AI
- **场景**：工商业屋顶电站
- **价值**：实现"无人化"日常巡检，运维成本下降 40%
- **来源**：华为计算 2023-02 报道，星逻智能官方

### 5.4 越南 100 MW 地面电站（出海案例）

- **设备**：大疆 T50P + 4G 链路
- **挑战**：高温高湿、热带季风、远离电网
- **方案**：4G 实时回传 + 云端 AI + 离线本地复核
- **成果**：单 MW 巡检成本降至 60 元（人民币口径），相对国内同类方案再低 30%

## 八、作业流程规范

### 8.1 飞行前

1. 调取电站 GIS 边界 + 组件排布图
2. 规划航线（航高 30—80m，航向与阵列平行，重叠率 ≥70%）
3. 检查 RTK 差分链路、空域申报、气象条件（辐照度 ≥ 500 W/m²）
4. 红外载荷校温（黑体校准 30—60 ℃）

### 8.2 飞行中

1. 起飞—爬升—航线巡航—降落全流程 RTK 记录
2. 红外 + 可见光同步采集，帧率 30Hz
3. 实时监控图传，异常区域即时放大复检
4. 机巢作业：自动充换电、数据自动回传

### 8.3 飞行后

1. 数据上传至 AI 引擎（边缘 / 云端）
2. AI 缺陷识别 + 人工复核（C/D 级必须人工复核）
3. 生成缺陷工单 + GIS 热力图
4. 输出 PR 评估报告、对比历史基线
5. 推送至维修团队 / 客户大屏

## 十、常见问题与避坑

### Q1：阴雨天能不能飞？

**A**：红外精度大幅下降，不推荐常规飞行。多云候补或雨后 1—2 小时可补飞，但热斑检出率会下降 30—50%。务必检查辐照度 ≥ 500 W/m²。

### Q2：水面 / 玻璃反射怎么处理？

**A**：（1）调整航高避开镜面反射角；（2）使用偏振滤镜；（3）红外 + 可见光融合；（4）增加同一区域重复扫描次数。

### Q3：屋顶电站需要注意什么？

**A**：（1）禁飞区与报备；（2）屋面承重限制；（3）电磁干扰；（4）GPS 多径效应，建议使用 RTK + PPK 双保险。

### Q4：AI 误检怎么办？

**A**：分级处理 —— A/B 级自动归档作为趋势分析，C/D 级必须人工复核 + 现场抽检 5%—10%。持续累积误检样本训练模型。

### Q5：如何评估方案效果？

**A**：四个核心指标 ——（1）热斑检出率（>90%）；（2）误检率（<10%）；（3）单 MW 巡检时间（<0.1 人天）；（4）维修响应时效（<72h）。

## 十一、未来趋势

### 11.1 2026—2028 三个确定性方向

1. **大模型加持**：Qwen3.5-2B 边缘端实时缺陷标注建议（实测可行，CSDN 2026-01）
