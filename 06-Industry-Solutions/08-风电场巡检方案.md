# 风电场巡检方案

> 叶片 / 塔筒 / 机舱 / 海缆 —— 无人机风电场巡检全流程
>
> 数据截止：2026-07 ｜ 适用：中国大陆陆上风电、海上风电（潮间带与近海）

---

## 一、方案概述

### 1.1 为什么必须用无人机

截至 2025 年底，中国累计风电装机 **超 5.4 亿千瓦**（国家能源局口径），其中陆上风电 4.5 亿千瓦、海上风电 0.9 亿千瓦，居全球第一。陆上单机主流 4—8 MW，海上单机已突破 18 MW。

风电运维的痛点集中在三个层次：

- **高度不可达**：陆上塔筒高度 100—150 m，海上可达 200 m；人工高空作业风险极高
- **叶片缺陷占比 60%+**：是风机失效的第一大类，但叶片在转动 / 静止两种状态下检查方式截然不同
- **海上风电运维成本占总成本 25—35%**：出海窗口、海况、人员调度决定了传统方案不可持续

**无人机 + AI 缺陷识别** 把叶片单次巡检时长从人工 4—8 小时 / 台降到 **30—60 分钟 / 台**，单台风机年巡检成本从 8—15 万元降到 **1—3 万元**，且能做到停机时长可控。

### 1.2 三大典型场景

| 场景 | 单机规模 | 巡检重点 | 推荐机型 |
|------|---------|---------|---------|
| **陆上风电** | 3—8 MW | 叶片 + 塔筒 + 机舱 + 集电线路 | 长航时多旋翼 + 固定翼 |
| **海上风电（潮间带）** | 6—12 MW | 叶片 + 海缆登陆段 + 防腐 | 长航时多旋翼 + 5G/卫星 |
| **海上风电（近海）** | 8—18 MW | 叶片 + 塔筒 + 内部结构 + 海缆 | 固定翼 + 垂直起降 + 卫星通信 |
| **分散式 / 老旧机组** | <2 MW | 叶片 + 塔筒腐蚀 + 接闪器 | 中型多旋翼 |

### 1.3 与传统方案对比

| 对比项 | 传统人工（蜘蛛人 + 望远镜） | 无人机多模态 |
|--------|----------------------------|-------------|
| 单台叶片巡检时长 | 4—8 h | 30—60 min |
| 单台风机年成本 | 8—15 万元 | 1—3 万元 |
| 高空作业风险 | 高（每年多起坠落事故） | 零人员风险 |
| 缺陷检出率 | ~70%（依赖工人经验） | >92%（AI 多模态融合） |
| 数据可追溯 | 报告 + 照片 | 全量数字化 + GIS 定位 |

## 二、典型缺陷类型与诊断逻辑

### 2.1 叶片缺陷分类

叶片是风机最大价值部件（占整机成本 15—20%），也是失效最频繁部件。典型缺陷 7 类：

| 缺陷类型 | 物理特征 | 检测手段 | 严重等级 |
|---------|---------|---------|---------|
| **横向裂纹** | 表面横向微裂纹 | 可见光高分辨率 + AI | 中 |
| **纵向裂纹** | 表面纵向裂纹 | 可见光 + 边缘检测 | 中 |
| **前缘腐蚀** | 迎风面前缘涂层脱落 | 可见光 + 多光谱 | 重 |
| **后缘开裂** | 后缘开裂 / 撕裂 | 可见光 + 红外 | 重 |
| **雷击损伤** | 表面烧痕 / 凹坑 | 可见光 + 红外 | 紧急 |
| **排水孔堵塞** | 排水孔堵塞 | 可见光 + 红外 | 轻—中 |
| **表面污垢 / 油渍** | 表面污染 | 可见光 + 多光谱 | 轻 |
| **分层 / 脱粘** | 内部层间分离 | 红外 + EL（地面） | 重 |

### 2.2 塔筒 / 机舱缺陷

| 缺陷类型 | 检测手段 |
|---------|---------|
| 塔筒焊缝裂纹 | 可见光 + AI 边缘检测 |
| 塔筒腐蚀 | 可见光高分辨率 + 多光谱 |
| 螺栓松动 | 可见光 + AI 目标检测 |
| 航空障碍灯失效 | 可见光夜间巡查 |
| 振动异常 | 无人机搭载微型振动传感器（实验） |

### 2.3 海缆与集电线路

- **海缆登陆段**：可见光 + 多光谱 + 红外，检查裸露、悬空、热异常
- **集电线路（同陆上输电）**：见 [01-电力巡检方案](./01-电力巡检方案.md)

### 2.4 缺陷分级

- **A 级（轻微）**：表面污垢、小面积涂层脱落——下次常规维护
- **B 级（中等）**：裂纹 < 30 cm，前缘轻腐蚀——3 个月内维修
- **C 级（严重）**：裂纹 > 30 cm，明显分层 / 脱粘——立即停机检修
- **D 级（紧急）**：雷击、断裂、塔筒结构异常——立即隔离

## 三、硬件配置清单

### 3.1 飞行平台

| 平台 | 续航 | 适用 | 代表机型 |
|------|------|------|---------|
| 长航时多旋翼 | 50—90 min | 陆上风电 / 潮间带 | 大疆 M350 RTK / T60 |
| 垂起固定翼 | 90—150 min | 海上风电跨海 | 纵横 CW-15 / 复亚 |
| 工业级直升机 | 60—120 min | 高精度悬停叶片巡检 | 自研 / Bell 等 |
| 室内 / 塔筒内 | 15—25 min | 灯笼无人机叶片内腔 | 西安光环 2026-07 新品 |

> **行业新动向（2026-07）**：灯笼型室内无人机已进入风电叶片内腔检测，解决了传统叶片"只能看外面、看不清内部"的核心痛点——叶片内腔腐蚀、分层、排水系统的无损检测成为可能。来源：西安光环 2026-07-24 微信公众号。

### 3.2 任务载荷

| 载荷 | 用途 | 关键指标 |
|------|------|---------|
| **可见光高分辨率相机** | 裂纹 / 涂层 / 鸟粪 / 排水孔 | 全画幅 4/3 CMOS，4500 万像素，机械快门 |
| **红外热像仪** | 分层 / 脱粘 / 内部积水 | 640×512 @ 30Hz，NETD ≤ 40mK |
| **多光谱相机** | 表面污垢 / 涂层老化 | 5—10 波段 |
| **激光雷达** | 塔筒变形 / 海缆地形 | 100—200m 测距，5cm 精度 |
| **EL 检测（地面）** | 内部层间 / 雷击 | 配合吊篮使用 |
| **微波湿度传感器**（实验） | 叶片内部湿度 | 5—10 GHz 微波 |

### 3.3 通信与定位

| 链路 | 距离 | 适用 |
|------|------|------|
| 4G/5G 蜂窝 | 全网覆盖 | 陆上、近海潮间带 |
| 卫星互联网（亚太 6D / 中星 26） | 全球 | 远海、跨海 |
| 北斗短报文 | 全国 | 应急 |

定位精度要求：RTK 厘米级（叶片 50m 高空定位 ±2cm）。

### 3.4 抗风与防护

- **抗风等级**：≥ 14 m/s（7 级），可短时抗 17 m/s（8 级）
- **防护等级**：IP54 起，海上作业建议 IP55
- **盐雾处理**：海上机型必须经过盐雾 96h 试验

### 4.1 AI 缺陷识别算法

### 4.2 缺陷生命周期追踪

风电运维的特殊性：**缺陷会演化**。一张 2023 年 A 级的裂纹，到 2025 年可能变成 C 级，因此：

- 每次巡检结果必须按风机编号 + 缺陷 ID 入库
- AI 自动对比基线库，标记"演化中"缺陷
- 维修完成后回填实际处理方式，反哺模型训练

## 五、典型案例

### 5.1 金风科技陆上风电场（新疆）

- **设备**：长航时多旋翼 + 4K 可见光 + 红外
- **规模**：300 MW，150 台机组
- **周期**：季度全检 + 月度重点机组
- **成果**：单台风机巡检时长从 6 h 降到 45 min；雷击损伤发现率提升 4 倍

### 5.2 远景能源海上风电（江苏）

- **设备**：垂起固定翼 + 卫星通信
- **规模**：400 MW 海上项目，200+ km 离岸
- **挑战**：海况窗口短（年均 90—120 天可出海）、盐雾、长距离数据回传
- **方案**：机巢部署在运维船上 + 卫星实时回传 + AI 边缘推理
- **成果**：叶片巡检成本降至 1.5 万元/台 / 年，海缆登陆段异常 30 天前预警

### 5.3 明阳智能复合材料叶片内腔检测

- **设备**：灯笼型室内无人机
- **场景**：叶片内腔腐蚀、分层、排水系统
- **价值**：填补"叶片内部看不见"行业空白，避免内部分层导致突发断裂
- **来源**：武汉中科 2026-03-14 演讲嘉宾案例（东方风力发电网）

### 5.4 电气风电 + AI 损伤预测

- **方案**：基于 AI 对风电机组叶片损伤预测应用研究项目
- **核心**：通过历史巡检数据训练大模型，预测未来 12 个月叶片缺陷演化趋势
- **来源**：风能专委会 CWEA 2026-03-27 项目启动

## 八、作业流程规范

### 8.1 飞行前

1. 与场站沟通停机计划（多数场景需叶片锁定在 9 点钟方向）
2. 调取 GIS 风机坐标、海缆图、场站布局
3. 规划航线：单台风机一般 8—12 个航点，覆盖叶片 + 塔筒 + 机舱
4. 抗风评估（持续风速 ≤ 12 m/s，阵风 ≤ 17 m/s）
5. 应急备案：坠落预案、空域申报

### 8.2 飞行中

1. RTK 起降点定位（机巢自动化）
2. 单风机 8—12 个航点，每个航点悬停 30—60s
3. 叶片正反两面分别采集（重叠率 ≥ 80%）
4. 实时监控图传 + 边缘 AI 实时标注
5. 数据通过 5G / 卫星实时回传

### 8.3 飞行后

1. 数据上传至 AI 引擎
2. AI 缺陷识别 + 人工复核
3. 缺陷按风机 + 缺陷 ID 入库
4. 输出缺陷生命周期对比 + 维修工单
5. 与上一次结果对比，标记"演化中"缺陷

## 十、常见问题与避坑

### Q1：风机必须停机吗？

**A**：必须停机。带电旋转叶片无人机会被瞬间击毁，且无法稳定悬停拍摄。停机后叶片需手动锁定 9 点钟方向。

### Q2：风速多少能飞？

**A**：建议持续风速 ≤ 12 m/s（6 级），阵风 ≤ 17 m/s（8 级）。海上风电窗口期短是核心痛点，需要机巢 + 卫星方案才能在窗口期最大化作业。

### Q3：叶片内腔怎么检？

**A**：灯笼型室内无人机（西安光环 2026-07）。这是 2026 年新能力，传统无人机无法进入 5—10m 深的叶片内腔。

### Q4：AI 误检率高怎么办？

**A**：分级处理 + 持续训练。陆上风电典型误检率 8—15%，通过累积 6—12 个月数据后能降到 5% 以下。

### Q5：海缆巡查怎么做？

**A**：可见光 + 红外 + 多光谱组合。海缆登陆段建议每月 1 次，全段每季度 1 次。出海窗口紧的运维船应部署机巢。

## 十一、未来趋势

### 11.1 2026—2028 三个确定性方向

1. **大模型加持**：叶片缺陷描述从"坐标+分类"升级到"语义级缺陷评估"（参考 Coovally AI CEA-DETR 案例）
2. **灯笼无人机普及**：叶片内腔检测从 0 到 1，2026—2027 全面落地
3. **AI 寿命预测**：从"现在有没有坏"升级到"未来会不会坏"（CWEA 2026-03 项目）

### 11.2 三个待突破

1. **塔筒振动在线监测**：当前振动监测依赖传感器，无人机搭载微型振动传感器是方向
2. **海上抗风等级提升**：需突破 8 级以上抗风 + 抗盐雾
3. **叶片内腔定量评估**：从"看见缺陷"升级到"测量尺寸 / 量化剩余寿命"
