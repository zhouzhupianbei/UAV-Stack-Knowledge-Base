# 无人机核心术语表

> 掌握电调/飞控/IMU/RTK/MAVLink 等核心概念 —— 新手入门必备

---

## 一、飞行平台相关

### 多旋翼（Multirotor）

由**3 个以上旋翼**组成的无人机，通过改变各旋翼转速实现姿态控制。

| 类型 | 旋翼数量 | 特点 |
|------|---------|------|
| 三旋翼 | 3 | 较少见、机械结构复杂 |
| 四旋翼 | 4 | 最常见、结构简单（如 DJI Mavic） |
| 六旋翼 | 6 | 载重更大、冗余度高 |
| 八旋翼 | 8 | 工业级、高可靠性要求 |

### 固定翼（Fixed-wing）

靠**机翼产生升力**，需要滑跑起飞或弹射，续航长、速度快。

- ✅ 优点：续航 1-4 小时、速度 60-150km/h、载重大
- ❌ 缺点：需要起降场地、不能悬停

### 垂起固定翼（VTOL）

**垂直起降 + 固定翼巡航**，结合两者优点。

- 起飞降落：多旋翼模式（垂直）
- 巡航飞行：固定翼模式（高效）

### 电调（ESC - Electronic Speed Controller）

**控制电机转速**的电子装置，接收飞控指令，调节输出电流。

| 参数 | 说明 |
|------|------|
| 持续电流 | 如 30A、40A、60A，决定能驱动多大电机 |
| 支持电池 | 如 3-6S 锂电 |
| 协议 | PWM、Oneshot、Dshot 等 |

### 飞控（Flight Controller）

无人机的**"大脑"**，处理传感器数据、执行控制算法、输出电机指令。

**核心功能：**
- 姿态解算（IMU 数据融合）
- PID 控制（稳定飞行）
- 导航定位（GPS 航线飞行）
- 故障保护（失控返航、低电量返航）

**常见飞控：**
- 开源：Pixhawk、ArduPilot、PX4
- 商业：DJI A3/N3、极飞 P150

## 二、传感器相关

### IMU（Inertial Measurement Unit）

**惯性测量单元**，测量加速度和角速度，用于姿态解算。

**组成：**
- 加速度计（3 轴）
- 陀螺仪（3 轴）
- （有时包含磁力计）

**关键指标：**
- 零偏稳定性
- 噪声密度
- 采样频率

### GPS（Global Positioning System）

**全球定位系统**，提供位置、速度、时间信息。

| 系统 | 所属国家 |
|------|---------|
| GPS | 美国 |
| 北斗（BDS） | 中国 |
| GLONASS | 俄罗斯 |
| Galileo | 欧盟 |

### RTK（Real-Time Kinematic）

**实时动态差分定位**，将 GPS 精度从米级提升到厘米级。

**原理：**
1. 地面基站（已知精确坐标）
2. 接收卫星信号，计算误差
3. 将误差修正量发送给无人机
4. 无人机修正自身定位

**精度对比：**
- 普通 GPS：±2-5 米
- RTK：±1-2 厘米

### 气压计（Barometer）

测量**大气压力**，推算高度。

- 优点：垂直分辨率高（厘米级）
- 缺点：受温度、气流影响
- 用途：定高飞行、高度辅助

### 光流传感器（Optical Flow）

通过**分析图像运动**估算无人机位移。

- 用途：室内定位、无 GPS 环境悬停
- 限制：需要纹理表面、光照充足

### 激光雷达（LiDAR）

发射**激光脉冲**测量距离，生成三维点云。

**应用：**
- 地形测绘
- 电力线检测
- 三维建模
- 避障系统

## 三、通讯协议相关

### MAVLink（Micro Air Vehicle Link）

无人机**最通用的通讯协议**，轻量、开源、可扩展。

**特点：**
- 轻量级（消息头仅 10 字节）
- 支持多种传输方式（串口、UDP、TCP）
- 丰富的消息类型（心跳、姿态、控制等）

**常用消息：**
- `HEARTBEAT`：心跳包
- `ATTITUDE`：姿态信息
- `GLOBAL_POSITION_INT`：位置信息
- `COMMAND_LONG`：控制命令

### DJI SDK

大疆提供的**开发工具包**，分为：

| SDK | 用途 |
|-----|------|
| Onboard SDK | 机载计算机开发（如 Manifold、Jetson） |
| Mobile SDK | 移动端 App 开发（iOS/Android） |
| Payload SDK | 负载开发（如云台相机、喊话器） |
| Cloud API | 云端对接（机库调度、远程指挥） |

### ROS/ROS2（Robot Operating System）

**机器人操作系统**，提供分布式通信框架。

- ROS：一代，基于 XML-RPC
- ROS2：二代，基于 DDS，支持实时性

**无人机集成：**
- px4_ros2：PX4 飞控的 ROS2 接口
- micro-ROS：嵌入式设备的 ROS2 实现

## 四、图传相关

### 模拟图传（Analog）

**传统图传技术**，延迟低（<10ms），但画质一般。

- 频段：5.8GHz 为主
- 距离：1-10km（视功率和天线）
- 用途：FPV 竞速、视距内飞行

### 数字图传（Digital）

**数字编码传输**，画质好、抗干扰强。

| 方案 | 延迟 | 画质 | 距离 |
|------|------|------|------|
| DJI O3 | 120ms | 1080p/60fps | 15km |
| DJI Air Unit | <50ms | 1080p | 10km |
| Walksnail | 30ms | 1080p | 10km |
| HDZero | <30ms | 720p | 5km |

### RTMP（Real-Time Messaging Protocol）

**直播推流协议**，用于无人机视频上云。

- 延迟：2-5 秒
- 用途：远程监控、直播
- 配合：ZLMediaKit、Nginx-rtmp

### SRT（Secure Reliable Transport）

**低延迟传输协议**，抗网络抖动。

- 延迟：0.5-2 秒
- 用途：专业直播、远程操控
- 优势：弱网环境下稳定

## 五、AI 与算法相关

### YOLO（You Only Look Once）

**实时目标检测算法**，速度快、精度高。

**版本演进：**
- YOLOv3：经典版本
- YOLOv5：工程化优化
- YOLOv8：最新 SOTA

**无人机应用：**
- 电力巡检（绝缘子破损识别）
- 安防监控（人员/车辆检测）
- 农业（病虫害识别）

### SLAM（Simultaneous Localization and Mapping）

**即时定位与地图构建**，在无 GPS 环境导航。

| 类型 | 传感器 | 代表算法 |
|------|-------|---------|
| 视觉 SLAM | 相机 | ORB-SLAM、VINS |
| 激光 SLAM | 激光雷达 | LOAM、LIO-SAM |

### 边缘计算（Edge Computing）

在**设备端直接处理数据**，减少云端传输。

**无人机边缘设备：**
- NVIDIA Jetson（Orin、Nano）
- 树莓派（4、5）
- 国产边缘盒（瑞芯微、晶晨）

## 六、GIS 与测绘相关

### 正射影像（Orthophoto）

经过**几何校正**的航拍图像，消除地形起伏影响。

- 用途：地图制作、面积量测
- 精度：取决于 GSD（地面采样距离）

### 倾斜摄影（Oblique Photography）

从**多个角度**拍摄同一区域，生成三维模型。

**常见方案：**
- 五镜头相机（前后左右 + 垂直）
- 单镜头多角度飞行

### 点云（Point Cloud）

大量**三维坐标点**的集合，描述物体表面。

**数据来源：**
- 激光雷达扫描
- 摄影测量（密集匹配）

**格式：** LAS、LAZ、PCD、PLY

### Cesium

**开源三维地球引擎**，用于 Web 端展示。

- 支持格式：3D Tiles、glTF、OSGB
- 用途：无人机成果展示、数字孪生

## 七、政策与合规相关

### UOM 平台

**民用无人驾驶航空器综合管理平台**，民航局官方平台。

**功能：**
- 实名登记
- 飞行申请
- 空域查询
- 驾驶员管理

### 适航认证

无人机**符合安全标准**的认证。

| 类型 | 要求 |
|------|------|
| 轻型无人机 | 备案即可 |
| 小型及以上 | 需要适航证 |

### 禁飞区（No-Fly Zone）

**禁止飞行的区域**。

| 类型 | 示例 |
|------|------|
| 机场净空区 | 机场周边 20-55km |
| 军事管理区 | 军事基地、边防 |
| 政治敏感区 | 中南海、核电站 |
| 临时管制区 | 重大活动、灾害现场 |
