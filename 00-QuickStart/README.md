# 00-QuickStart：无人机入门指南

> 🚁 30 分钟了解无人机行业 —— 从零建立认知，开启你的低空经济之旅

---

## 📌 模块定位

本模块面向**零基础入门者**，提供无人机行业的系统性认知框架。不涉及复杂代码和深奥理论，专注于帮你快速建立行业全景图。

---

## 🎯 目标读者

- 对无人机行业感兴趣，但不知从何入手
- 想转行到低空经济领域的开发者
- 需要快速了解无人机的项目管理人员
- 学生群体，希望规划学习路径
